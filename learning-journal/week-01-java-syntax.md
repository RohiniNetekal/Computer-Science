## Java Setup & Syntax

### Short explanation
Java code runs on the JVM. JDK provides development tools; the JVM runs bytecode. Variables store typed values and control flow decides what executes.

### Handy example
```java
int amount = 100;
if (amount > 50) {
    System.out.println("Eligible");
}
```

### Key point
Remember: Java is statically typed; every variable has a type.
