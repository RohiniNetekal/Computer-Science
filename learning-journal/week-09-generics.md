## Generics

### Short explanation
Generics provide compile-time type safety and avoid unnecessary casts.

### Handy example
```java
List<String> names = new ArrayList<>();
names.add("Rohini");
String first = names.get(0);
```

### Key point
Remember: List<String> is safer than a raw List.
