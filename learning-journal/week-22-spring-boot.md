## Spring Boot Basics

### Short explanation
Spring Boot simplifies Spring applications with auto-configuration, starters and externalized configuration.

### Handy example
```properties
server.port=8080
spring.application.name=order-service
```

### Key point
Remember: Profiles allow environment-specific configuration.
