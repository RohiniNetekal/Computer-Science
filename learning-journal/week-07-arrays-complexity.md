## Arrays & Complexity

### Short explanation
An array stores a fixed-size sequence. Big-O describes how work grows with input size.

### Handy example
```java
int[] ids = {10, 20, 30};
for (int id : ids) {
    System.out.println(id);
}
```

### Key point
Remember: Direct array access is O(1); scanning an array is O(n).
