## AWS Fundamentals

### Short explanation
AWS provides managed building blocks such as compute, storage, databases and networking.

### Handy example
```text
API -> Load Balancer -> Compute
                     -> Managed DB
                     -> Object Storage
```

### Key point
Remember: Learn what each service solves before memorizing service names.

### Interview check
- What is it?
- Why would you use it?
- What is one common mistake or trade-off?
