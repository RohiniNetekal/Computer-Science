# Computer Science — Backend Engineering Learning Lab

A growing, hands-on learning repository focused on concepts that matter for Java backend development and interviews.

> **Note:** Everything in this repository is personal learning/demo work. It does not represent production code from any employer or client project.

## Current module

### Core Java: Collections & Streams — Order Analytics

A small Java 17 example that models a common backend reporting problem: aggregate orders by status, calculate totals, and find the highest-value order using the Stream API.

**Concepts demonstrated**
- Records for immutable data
- `List` and `Map` collections
- Stream filtering and mapping
- `groupingBy` and `summingDouble`
- Sorting and `max`
- Separating transformation logic into focused methods
- Time/space complexity reasoning

See [`core-java/collections-streams/OrderAnalytics.java`](core-java/collections-streams/OrderAnalytics.java) for the implementation.
