## Git Fundamentals

### Short explanation
Git tracks versions through commits and branches. A good commit represents one logical change.

### Handy example
```bash
git checkout -b feature/offer-search
git add .
git commit -m "Add offer search API"
```

### Key point
Remember: Write commit messages that explain the change, not the debugging process.

### Interview check
- What is it?
- Why would you use it?
- What is one common mistake or trade-off?
