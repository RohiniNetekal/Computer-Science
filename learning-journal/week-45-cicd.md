## CI/CD Basics

### Short explanation
CI automatically builds and tests changes; CD automates delivery/deployment through environments.

### Handy example
```text
Push -> Build -> Unit Tests -> Package -> Deploy -> Verify
```

### Key point
Remember: Fast automated tests make frequent delivery safer.
